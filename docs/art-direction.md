# Арт-направление: Lineage 2 — Башня Крумы

Цель — ностальгия для игроков 35+, которые помнят L2. Сеттинг: Башня Крумы (Cruma Tower)
и окружающие её болота. Всё ниже — опорные факты из исследования (2026-11), чтобы не выдумывать.

## Тон текстов

Игра разговаривает **насмешливо и подтрунивающе** — башня издевается над игроком, но без злобы.
Тексты уже переведены в этот тон (меню, геймовер, модалка сдачи) — все новые писать так же.

- обращение к игроку: «герой», «смертный»;
- проигрыш — высмеивается, бегство — высмеивается дважды;
- отсылки L2: адена, SOE (свиток возвращения), «в город», башня, лава.

Примеры: «считай в уме. если сможешь», «Сбежал. Классика жанра.», «серия без косяков»,
«Остаться и терпеть» / «Сбежать (SOE)», «Уползти в город».

## Мир: Башня Крумы (классика, Interlude)

Болота Cruma Marshlands, башня гигантов, 3 этажа, мобы 40–55.

### Этаж 1 (40–45)
Porta (40), Excuro (41), Catherok (42), Mordeo (42), Ricenseo (43), Snipe (44),
Shindebarn (44), Krator (44), Premo (45, гигант), **сундуки Treasure Chest** (42–45,
в том числе **взрывающиеся**).
Рейд-босс: **Archon Suscepter** (45).

### Этаж 2 (46–50)
Validus (46), Ossiud (47), Dicor (47), Perum (48), Liangma (49), Torfe (49),
Dark Lord (50), Death Knight (50) + свита Dark Knight / Soldier of Darkness.
Рейд-босс: **Carnamakos** (50).

### Этаж 3 (49–55)
Охрана: Susceptor (49), Doom Wraith (55).
Финальный босс башни: **Core** (50) — механическое сердце Крумы (в L2M — Core Suspector на 7F).

### Маппинг на наш геймплей (фаза 1)

- **этажность бесконечная**: башни-«верха» нет, сложность нарастает по мере подъёма;
  классические 1F/2F/3F Крумы — повторяющиеся тиры контента с усилением, а не весь мир;
- монстры этажа = бои из фазы 1: имена и HP по этажу (мобы 1F слабее 2F/3F);
- рейд-боссы как «крепкие» этажи: Archon Suscepter → Carnamakos → Core (вершина);
- этажи-сокровищницы = **Treasure Chest**, включая взрывающиеся сундуки-ловушки (риск/награда);
- «Сбежать» = **Scroll of Escape (SOE)** — свиток телепорта в город, классика L2.

## Визуал: L2 UI

- окна: полупрозрачный тёмно-синий градиент `#1a2438 → #0d1524`,
  тонкая бронзово-золотая рамка `#b89552 / #8c6d34`, заголовки золотистым `#e8d5a3`;
- системные сообщения — жёлтым `#ffd964`, в духе «You have earned 1 adena»;
- HP-бар красный `#c1272d` (задел под шкалы монстров), MP — синий;
- палитра Крумы: холодный камень `#3a4454`, болотная зелень `#4a5d3a`, мрак `#0d1117`,
  лава-оранжевый акцент `#ff8a3d` (уже в теме MVP).

Текущая тёмная тема — промежуточная; полный L2-редизайн — отдельная задача (токены в `@theme`).

## Правило «Сдаться» (реализовано в MVP)

- кнопка «Сдаться» на экране игры → модалка «Сдаёшься?» («Сбежать (SOE)» / «Остаться и терпеть»);
- **модалка не ставит игру на паузу никогда**: оверлей прозрачен для кликов, игра остаётся
  активной, глобальное и локальное время продолжают идти (сейчас таймеров нет — правило
  зафиксировано на будущее);
- «Сбежать» = FSM-действие `RUN/SURRENDER` → `endReason: 'surrender'`: адена сохраняется,
  экран итогов встречает заголовком «Сбежал. Классика жанра.».

для использования в приложении. Что собираем и откуда:

| UI-стилистика (окна, кнопки, бары) | официальный сайт, l2wiki.com, Fandom-вики, Pinterest-подборки, NCSoft artbook |
| Картинки (мобы, боссы, иконки, фоны) | l2wiki (портреты мобов), l2-servera.com, Fandom, скриншоты классики |
| Музыка | Bill Brown OST (Spotify/SoundCloud), YouTube-плейлисты L2 OST |

### Применение ассетов по экранам (решено 2026-11-04)

- **Экран игры = один из этажей Крумы**: визуал этажа-локации берём с реальных этажей Крумы
  (тиры 1F/2F/3F циклятся по бесконечной башне, крепость растёт с уровнем сложности).
- **Главное меню = вход в Круму**: арт/сцена входа в башню.
- **Музыка — оттуда же**: темы Крумы/подземелий L2 (конкретный трек найти при сборе;
  кандидат — The Dark Dungeon; Dion Theme остаётся запасным для меню).
- **Иконки** — стилистика L2: адена, бутыли, свиток SOE, щитовые пластины, ядра заморозки.
- **Кнопки** — L2 UI: тёмно-синие окна, бронзово-золотые рамки, золотистые заголовки
  (токены в разделе «Визуал: L2 UI»).
- **Цветокор** — палитра Крумы: холодный камень, болотная зелень, мрак + лава-оранжевый акцент.

Целевая структура в репо:

```
public/assets/
  images/    # фоны, мобы, иконки предметов
  music/     # темы меню/башни/боссов
  sfx/       # удары, двери, лава, сундуки
```

⚠️ Права: всё про L2 — IP NCSoft. Для приватного прототипа — терпимо; перед публичным
релизом ассеты заменить или лицензировать (уже отмечалось для музыки — касается и картинок).
