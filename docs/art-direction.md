# Визуальное направление

## Текущий стиль

- **UI-кнопки и панели**: CSS-классы `.l2-button`, `.l2-button-lg`, `.l2-panel` (border-image из PNG-ассетов, вырезанных со скриншота — см. `scripts/extract-menu-assets.mjs`).
- **Меню**: фон — скриншот тронного зала (очищенный от UI-блоков, `public/assets/images/menu-bg.jpg`) + канвас с анимированными огнями (`components/MenuBackground`).
- **Игра (wall-runner)**: тёмная дорога в перспективе, SVG-стены, свечение лавы снизу.
- **Тон текстов**: насмешливый и подтрунивающий.

## Ассеты

```
public/assets/images/
  menu-bg.jpg         # фон меню (1680×1050 → кроп 1245×920)
  button-start.png    # большая кнопка (139×44)
  button-small.png    # малая кнопка (114×36)
  panel-frame.png     # панель-подложка (269×114)
  source/menu.jpg     # оригинальный скриншот (не используется в рантайме)
```
