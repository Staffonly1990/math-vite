# Math — концепт игры и стек

## Игра

Тренажёр устного счёта в обёртке **FPV wall-runner**: 4-полосная дорога уходит к горизонту,
полупрозрачные стены-трапеции летят на игрока — на каждой шапка с примером и 4 ячейки-ответа.
Тап по ячейке = пролёт через её полосу. Ошибка = удар, скорость падает, лава ближе.
Серия верных = мультипликатор скорости ×1→×3.

Главная фишка: всё считается **в уме**, в потоке, без остановок. Каждый клик = действие.

## Текущий прототип (2026-11-06)

**Работает и проверено живьём** (81/81 теста, build зелёный):

- SVG-дорога в перспективе (4 полосы сходятся к горизонту)
- Стены-трапеции от края до края, шапка с примером, 4 ячейки
- Тап по ячейке = ответ: верно → адена+, скорость+, лава+; неверно → HP−, скорость=1
- Таймаут стены (не успел тапнуть) = авто-промах
- Лава = глобальный таймер (10с старт, +2с за верный, кап 20с)
- Мультипликатор ×1→×1.2→×1.4→... (за серию, сброс при ошибке)
- Яд-ячейки (зелёная полоска, ~12% шанс, урон 2 + яд при ошибке)
- Бонус-ячейки (золотая рамка, ~6% шанс, лечение/щит/+лава)
- Уровень = floor(верных/5)+1 — лестница математики
- Сдача (SOE), gameover-экран с итогами

## Механики

### Стена

Стена — единая преграда во всю ширину дороги, разделена на 4 полосы:

- **шапка**: пример («47 + 54 = ?»), едет вместе со стеной, масштабируется с расстоянием;
- **4 ячейки**: трапеции, каждая на всю ширину своей полосы, без зазоров;
- **тело полупрозрачное** — сквозь него видно следующую стену;
- **числа плотные**, непрозрачные.

### Тап по ячейке

| Результат | Что происходит |
|---|---|
| **Верно** | Стена раскалывается, адена+уровень, скорость +0.2, лава +2с |
| **Неверно** | Урон (1 обычная, 2 ядовитая), скорость = 1, лава −1с |
| **Ядовитая** | Если ошибка на ней — урон 2 + яд (+1 стак) |
| **Бонусная** | 40% лечение / 30% щит / 30% +3с лавы (даже при верном ответе) |
| **Не успел** | Авто-промах: лава −1с, скорость = 1, серия сброшена |

### Лава

Глобальный таймер на весь забег. Тикает по wall-clock (пауз нет никогда).
Старт 10с, +2с за верный, −1с за промах, кап 20с. Кончилась — gameover.

### Скорость

Мультипликатор растёт за серию: ×1.0 → +0.2 за каждый верный → кап ×3.0.
Определяет скорость приближения стен: чем быстрее — тем меньше времени на решение.
Сброс при любой ошибке.

### Уровень и лестница математики

Уровень растёт каждые 5 верных ответов. Адена за верный = номер уровня.

Лестница (растёт с уровнем):
- ур.1 — `+`
- ур.2 — `+ −`
- ур.3 — `+ − ×`
- ур.4+ — `+ − × ÷` (деление только нацело)
- ур.5 — третье число (не реализовано)
- ур.6+ — микс знаков (не реализовано)

Полная лестница тем — [math-topics.md](math-topics.md).

### HP, щит и яд

- Игрок: 3 HP, щит (поглощает урон до HP), яд (стаки, не тикает в этой версии).
- Яд-ячейка при ошибке: урон 2 + +1 стак яда. Яд визуализируется в HUD.
- Инвариант: яд применяется только при касании HP (щит блокирует).

## Архитектура

Конвенции — [conventions.md](conventions.md).

Ядро — **чистый TypeScript без React/DOM** (классы + фабрики):

```
src/
  game/
    wall/
      WallGame.ts        # оркестратор: стены, лава, скорость, HP
      WallGame.test.ts
    wallFsm.ts           # тонкий адаптер: action → метод
    problem/             # генератор задач (арефметика сейчас)
    entities/
      Player.ts          # HP/щит/яд
      items/             # предметные классы (бонусы)
    rng.ts               # seeded PRNG
    difficulty.ts        # лестница математики
  stores/
    wallSession.ts       # стор забега
    settings.ts          # настройки
  screens/
    WallGameScreen/      # SVG-дорога + стены + HUD
    WallGameOverScreen/  # итоги забега
    MenuScreen/          # меню
  components/            # UI-компоненты
  lib/                   # утилиты
```

Правила:
1. `game/` не импортирует React.
2. Таймеры на timestamp, время — параметром (детерминизм).
3. Классы: методы вычисления в самом классе, без мутаций (возвращают новый объект).
4. Сериализация: toJSON/fromJSON у каждого класса.
5. Новые темы/типы стен — через union-типы и реестры.
